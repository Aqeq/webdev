# Quest 1: Navbar Basic

Buat navbar sederhana dengan 3 elemen: logo, link navigasi, dan tombol.

### Yang harus kamu lakukan:

**HTML:**
- `<nav>` sebagai container utama pakai flex
- Logo di kiri
- 2 link navigasi di tengah
- Tombol "Masuk" di kanan

**CSS Selector:**
- `nav` → flex container
- `.logo` → kiri
- `.nav-links` → tengah
- `.btn-login` → kanan

**JS:**
- Klik tombol "Masuk" → `alert("Selamat datang!")`
- Ambil teks logo → `console.log()`

> **File JS sudah disediakan di `script.js`!** Tinggal baca dan pahami.

### Checklist:
```
[ ] 3 elemen sejajar dalam 1 baris
[ ] Logo kiri, link tengah, tombol kanan
[ ] Alert muncul saat klik tombol
```
